# Snacks & Postres

Plataforma web sencilla para toma y visualización de pedidos en tiempo real.

## Tecnologías
- Frontend: HTML5, CSS3, JavaScript
- Backend / DB: Supabase (PostgreSQL & Realtime) / Python (De momento)

## Flujo de trabajo con Git
1. `main`: Versión estable / final.
2. `dev`: Rama de desarrollo compartido.
3. Ramas personales: `feature/nombre de la persona`
