## 🎯 Objetivo del Día
Establecer la infraestructura inicial del backend a menor costo, conectar el entorno de desarrollo local y validar las operaciones de base de datos para el catálogo de productos de la repostería.

## 🚀 Actividades Realizadas
1. **Inicialización del Entorno Local:** 
   * Se creó el proyecto en Node.js y se configuró el cliente de Supabase (`@supabase/supabase-js`).
   * Se establecieron variables de entorno seguras (`.env`) aislando las credenciales de acceso.
   * Se resolvieron conflictos locales de red (IPv6) forzando la salida por IPv4 para la comunicación con el servidor.

2. **Modelado de Base de Datos:**
   * Se creó la tabla principal `public.productos` en Supabase.
   * Se implementó el campo booleano `es_temporada` para manejar dinámicamente postres por época (ej. Ponche Navideño).
   * Se preparó la columna `imagen_url` (aceptando nulos) para delegar el peso de las imágenes al Storage y evitar saturar los 500 MB de la base relacional.
   * Se desactivó temporalmente la seguridad RLS para habilitar pruebas de desarrollo.

3. **Validación de la API (Insomnia):**
   * Se documentó y comprobó el ciclo CRUD completo.
   * `GET`: Lectura exitosa del catálogo.
   * `POST`: Inserción de nuevos productos (Manejo de código 201).
   * `PATCH`: Actualización parcial de campos específicos (como las URLs de las imágenes).
   * `DELETE`: Eliminación correcta de registros (Manejo de código 204).
